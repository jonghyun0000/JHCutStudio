# 0.5 평가 기준 — 2026-09-25

현재 버전을 **100점 또는 34개 전부 완료로 평가할 근거는 없다.** 원래 완료 기준에 따른 상태는 [34개 기록](UPGRADE-0.5-WORKLOG.md), 실제 측정은 [STATUS](STATUS.md)에 있다. 20개는 구현·검사 범위를 충족했고 14개는 일부 구현 또는 외부 검증 대기다. 단순 기능 수로 총점을 올리지 않는다.

0.3의 내부 잠정 74점과 경쟁 앱 참고 점수는 [당시 평가](SCORECARD-0.3.md)로 보존했다. 이것은 0.5의 새 점수나 현재 CapCut Pro·Final Cut Pro·Premiere를 같은 장비에서 비교한 결과가 아니다. 이번에는 경쟁 앱을 직접 실행해 비교하지 않았으므로 새 순위·점수를 발표하지 않는다.

0.5에서 확인한 변화는 연결 편집과 교정 보존, 로컬 자막 생성, HDR 변환/HEVC/ProRes 출력, 믹스/감쇠, 실사 45분 출력 및 저장 장애 복구다. 전문 편집기로 평가하려면 실사 자막 오차·교정 시간, 장기 연속 재생/드롭, 검증된 true peak, 고급 색/추적/멀티캠, 공증과 타 장비 검사가 남아 있다. 기능 사용 가능성과 전문 작업에서의 신뢰성은 별도로 평가한다.
