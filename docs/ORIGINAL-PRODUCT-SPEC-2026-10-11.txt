공개 중립 명세 사본: 개인·업체 예시만 중립화했다. 기능·성능·초기 제외 범위·단계·검증 요구를 삭제하지 않았다. 원래 비공개 예시는 로컬에 보존된다.

너는 macOS 영상편집 소프트웨어의 수석 엔지니어이자
미디어 파이프라인 설계자다.

아래 명세를 바탕으로 사용자가 실제로 영상을 편집하고
출력할 수 있는 데스크톱 프로그램을 구현하라.

기획서, 랜딩페이지, 클릭만 되는 UI,
가짜 미리보기와 가짜 렌더링으로 끝내지 마라.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. 제품 목표와 사용자
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

가칭은 JH CUT Studio다.
기존 프로젝트에 이름이 있으면 유지한다.

사용자는 개인 크리에이터다.

초기 성능 예산의 예시 환경(현재 지원 인수 완료를 뜻하지 않음):
- M4 MacBook Pro.
- 메모리 16GB.
- SSD 512GB.

실제 OS·칩·메모리·개발도구는 작업 시작 시 확인한다.

주요 사용 목적:
- AI 생성 영상 여러 개를 연결한 광고.
- 영상 공모전 출품작.
- 인스타그램 릴스·유튜브 쇼츠.
- 가로형 유튜브 영상.
- 소매점·학생 커뮤니티·지역 사업 홍보 콘텐츠.
- 향후 단편영화·스토리 영상까지 확장 가능한 편집 기반.

주요 입력:
- iPhone 촬영 영상.
- Higgsfield·Kling·Veo 등에서 사용자가 받아 둔 영상 파일.
- 이미지·내레이션·BGM·효과음.

이 서비스들과의 API 연결을 기본 전제로 삼지 마라.

제품 방향:
‘정밀한 타임라인 편집 + 쉬운 숏폼 제작
+ 한국어 자막 + AI 클립 관리’.

경쟁 제품의 전체 복제품보다
사용자의 반복 작업을 줄이는 도구를 만든다.

로그인, 구독, 서버 업로드 없이
핵심 편집·저장·출력이 작동해야 한다.

자체 삽입 워터마크는 없다.

개발·유지보수·저장공간·선택형 외부 API의 비용까지
사라지는 것으로 설명하지 마라.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. 기존 프로젝트와 실행 환경 점검
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

먼저 다음을 확인한다.

- 현재 디렉터리와 프로젝트 구조.
- README와 AGENTS.md.
- Git 상태와 사용자의 미커밋 변경사항.
- 의존성.
- 기존 편집·재생·렌더링 기능.
- 테스트와 빌드 설정.

사용자의 변경사항을 덮어쓰거나
프로젝트를 무단 초기화하지 마라.

Mac에서는 sw_vers, uname -m,
xcodebuild -version, swift --version 등으로 환경을 확인한다.

기존 프로젝트가 있으면 현재 기술 스택과 작동 기능을
우선 보존한다.

재작성은 필수가 아니다.
대규모 전환이 필요하면 이유와 점진적 전환안을 문서화한다.

새 프로젝트의 기본 기술 구성:

- Swift + SwiftUI:
  앱 구조, 패널, 설정, 문서 화면.

- AppKit:
  정밀한 타임라인 입력, 드래그, 키보드,
  필요한 고성능 뷰.

- AVFoundation / Core Media:
  미디어 로딩, 시간 처리, 재생, 합성, 출력.

- Core Image / Core Text:
  영상 효과와 한국어 텍스트 렌더링.

- Metal / VideoToolbox:
  검증된 필요 구간의 GPU·코덱 가속.
  가속 여부를 추정하지 말고 확인한다.

- whisper.cpp:
  후속 단계의 로컬 음성인식 후보.
  버전과 모델을 고정하고 실제 한국어 샘플로 검증한다.

- FFmpeg:
  필요할 때만 전처리·분석·검증용 보조 도구.
  필수 렌더링 엔진을 무조건 두 개 만들지 마라.

설치된 안정 SDK와 호환되는 버전을 고정하고
최소 macOS 버전을 기록한다.

존재하지 않는 API나 설치되지 않은 의존성을 가정하지 마라.

새로운 클라우드 DB, 로그인, 결제, 웹 서버는
초기 범위에 넣지 않는다.

macOS/Xcode가 없는 환경에서는
빌드·GUI 실행을 했다고 주장하지 마라.

가능한 순수 로직 테스트를 수행하고
macOS 검증 절차와 미검증 항목을 별도로 남긴다.

개발용 실행과 공개 배포용 서명·공증을 구분한다.

3. 벤치마킹 범위와 구현 상태
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

다음은 제품 목표를 정하기 위한 참조다.

경쟁 제품의 구현 코드·전용 모델·유료 에셋을
복제하거나 호출할 수 있다고 가정하지 마라.

Final Cut Pro에서 참고할 기능군:

- 연결·리플 편집 개념과 정밀 트림.
- 복합 클립과 Roles.
- 키프레임과 속도 변경.
- 가변 속도·정지 프레임·역재생.
- 색상 휠·커브·LUT·색상 매칭.
- 오디오 정리.
- 프록시·미디어 재연결.
- 자동 자막.
- 대사·시각 검색.
- 비트 검출·컷 경계 검출.
- 객체 추적·마스킹·자동 리프레임.

고급 확장 대상으로만 검토:
멀티캠, FCPXML, HDR·RAW·공간 영상.

CapCut Desktop/Pro에서 참고할 기능군:

- 쉬운 다중 레이어 편집.
- 키프레임 그래프와 속도 곡선.
- 효과·전환.
- 자동 자막과 자막 스타일.
- 텍스트 기반 편집.
- 불필요한 말·쉼 제거.
- 자동 리프레임·자동 컷아웃.
- 보정·오디오 개선·TTS.
- 템플릿과 브랜드 리소스.
- 긴 영상의 숏폼화.
- AI 제작 도구.

CapCut 기능은 모두 Pro 전용이라고 단정하지 않는다.
플랫폼과 개별 기능·소재의 유료 표시를 구분한다.

Apple의 Motion·Compressor와 iPad 전용 기능도
Final Cut Pro Mac 본체 기능과 구분한다.

각 기능의 상태를 다음처럼 표시한다.

- 로컬 기본.
- 로컬 모델 필요.
- 외부 서비스 필요.
- 실험적.
- 미구현.

모델이 없는 AI 버튼은 이유와 설치 방법을 보여 주고
비활성화한다.

실제 기능이 없는 성공 메시지나
임의의 분석 결과를 만들지 마라.

4. 화면과 조작
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

한국어 우선 UI로 만든다.

다크 그레이 배경과 절제된 강조색을 사용한다.
경쟁 제품의 화면을 그대로 복제하지 않는다.

화면 구성:

상단:
프로젝트 이름, 저장 상태, 실행취소, 재실행, 출력.

왼쪽:
미디어, 자막, 오디오, 템플릿.

중앙:
영상 미리보기와 재생 컨트롤.

오른쪽:
선택한 클립·자막·오디오의 속성.

하단:
멀티트랙 타임라인.

패널 크기를 조절하고 접을 수 있어야 한다.
작은 화면에서는 고급 설정을 접어 편집 공간을 확보한다.

타임라인:
- 썸네일.
- 오디오 파형.
- 시간 눈금.
- 플레이헤드.
- 선택·드래그·트림 핸들.
- 스냅.
- 확대·축소.
- 화면 밖 항목 가상화.

선택한 클립의 위치·크기·회전은
미리보기에서도 조절할 수 있도록 단계적으로 확장한다.

기본 단축키:
- Space: 재생/정지.
- 방향키: 프레임 이동.
- Cmd+B: 분할.
- Cmd+Z: 실행취소.
- Shift+Cmd+Z: 재실행.
- Cmd+S: 저장.
- Delete: 선택 항목 삭제.

리플 삭제는 별도 명령으로 둔다.
고급 단계에서 J/K/L과 사용자 단축키 편집을 지원한다.

한국어 입력기 조합 중이거나
텍스트 필드에 초점이 있을 때는
편집 단축키가 문자를 지우거나 타임라인을 조작하지 않게 한다.

로딩, 빈 화면, 오류, 모델 미설치,
미디어 누락 상태를 구분한다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5. 편집 엔진의 필수 원칙
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Project → Sequence → Track → Clip 구조를 둔다.

다음 객체를 분리한다.
MediaAsset, AudioItem, Title, Caption, Effect,
Keyframe, Transition, Marker, ExportProfile, Job.

원본 미디어와 타임라인 배치를 별개 객체로 관리한다.

프로젝트 문서에는 다음을 저장한다.
- schemaVersion.
- 고유 ID.
- 영상 크기.
- 유리수 프레임레이트.
- 색공간.
- 미디어 참조.
- 편집 내용.
- 모델·폰트·에셋 출처.

절대 경로만 저장하지 말고
상대 경로·security-scoped bookmark·재연결 정보를
상황에 맞게 사용한다.

시간 처리를 부동소수점 초의 누적으로 구현하지 않는다.
CMTime 또는 동등한 유리수 모델을 사용한다.

원본의 시간과 타임라인 시간을 분리한다.
구간의 끝은 미포함으로 정의한다.

후속 단계의 30000/1001, 24000/1001도
손실 없이 저장할 수 있도록 한다.

변경은 검증 가능한 편집 명령으로 처리한다.

분할·이동·트림·삭제·속도 변경·스타일 변경에
실행취소와 재실행을 연결한다.

드래그 한 번은 하나의 undo 단위다.

음수 길이, 원본 범위 초과, 잘못된 참조,
잠긴 트랙 변경을 거부한다.

다음 동작을 구분한다.
- 일반 삭제: 빈 공간 유지.
- 리플 삭제: 지정된 동기화 범위의 뒤 요소를 당김.

연결 오디오·자막·오버레이의 이동 규칙을 명시한다.
연결 클립의 anchor와 속도 변경 후 처리 규칙을 테스트한다.

가장 중요한 원칙은 미리보기와 출력의 일치다.

- 하나의 TimelineIR/RenderPlan에서
  미리보기와 내보내기를 구성한다.

- 가능한 한 같은 합성기, 효과 평가,
  텍스트 레이아웃 코드를 공유한다.

- UI 위에만 표시되는 자막을
  출력 기능으로 간주하지 않는다.

- 여러 독립 재생기를 제각각 돌려
  동기화를 흉내 내지 않는다.

- 색공간, 회전 메타데이터, 크롭, 알파,
  글꼴 대체, 시간 매핑을 일관되게 처리한다.

- 지원하지 않는 효과를 조용히 빼고 출력하지 않는다.

첫 버전의 색공간은 SDR Rec.709로 제한한다.

HDR·Log 입력을 SDR이라고 재표시하지 마라.
검증된 변환 경로가 없으면
변환 필요 상태로 표시하고 출력을 막는다.

HDR 출력은 별도 검증 단계다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
6. 기본 편집 기능
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

파일 선택과 드래그로
영상·이미지·오디오를 가져온다.

컨테이너 확장자만 보고 호환된다고 판단하지 않는다.
실제 코덱·트랙·회전·프레임레이트·색정보를 읽고
지원 여부와 변환 필요 여부를 보여 준다.

단계적으로 제공할 편집 기능:
- 영상 분할.
- 앞뒤 트림.
- 순서 변경.
- 삽입과 덮어쓰기.
- 복제와 삭제.
- 빈 공간.
- 스냅.
- 다중 선택.

기본 구성:
메인 영상 트랙 + 이미지/영상 오버레이
+ 제목/자막 + 내레이션/BGM.

음소거·잠금·숨김 상태가
재생과 출력에 모두 반영되어야 한다.

영상 속성:
크기, 위치, 회전, 불투명도, 크롭,
화면 맞춤/채움, PNG 투명 배경.

화면 비율:
9:16, 16:9, 1:1, 4:5와 사용자 지정으로 확장한다.

비율 변경은 원본 시퀀스를 복제한 파생 버전에서 수행한다.
텍스트와 크롭을 독립 조절할 수 있어야 한다.

전환은 컷·페이드·디졸브부터 시작한다.

전환에 필요한 앞뒤 소스 여유 구간이 부족하면
길이 제한과 이유를 보여 준다.

프레임을 몰래 반복하거나
프로젝트 길이를 임의로 바꾸지 마라.

속도는 일정 배속부터 구현한다.
이후 가변 속도 곡선·정지 프레임·역재생으로 확장한다.

가변 속도는 원본 시간 매핑,
오디오 피치, 자막 위치를 함께 처리한다.

일반 프레임 복제·블렌딩과 광학흐름 보간을 구분한다.

키프레임은 위치·크기·회전·불투명도·볼륨부터 시작한다.
linear, hold, ease를 지원한다.

고급 곡선 편집은 기본 시간 매핑 검증 후 추가한다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
7. 한국어 자막과 오디오
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

자동 자막 이전에도 다음이 작동해야 한다.
- 한국어 제목.
- 수동 자막.
- SRT 가져오기·수정·내보내기.

폰트, 크기, 굵기, 색상, 외곽선,
배경, 정렬, 위치를 수정하고 프리셋으로 저장한다.

실제 설치된 글꼴을 사용한다.
없는 폰트는 명시적으로 대체한다.
폰트 파일을 무단 포함하지 마라.

로컬 STT는 whisper.cpp 어댑터로 분리한다.

한국어에는 영어 전용 .en 모델을 쓰지 않는다.

모델의 다운로드 출처·라이선스·체크섬·필요 공간을 표시하고
사용자 승인 후 설치한다.

작은 다국어 모델부터 품질과 메모리를 측정한다.

모델이 없거나 인식에 실패해도
수동 자막과 일반 편집은 가능해야 한다.

인식용 오디오는 타임스탬프를 보존하며
필요한 PCM으로 변환한다.

대사 전사를 원본 구간과 연결하고
컷·속도 변경 후 타임라인에 재매핑한다.

단어 단위 강조는 단어 타이밍이 있을 때만 제공한다.
추정 타이밍을 정확한 정렬이라고 표시하지 마라.

자막 편집:
- 문장 분할·합치기.
- 타이밍 보정.
- 검색.
- 일괄 스타일 변경.
- 한국어 줄바꿈.
- 화면 안전영역.

조합문자와 문장부호를 테스트한다.

2줄 제한과 안전영역은 사용자 설정이다.
플랫폼의 공식 규칙이라고 단정하지 않는다.

다음 두 명령을 반드시 구분한다.
- 전사 문장 삭제로 영상 자르기.
- 자막 문구만 수정하기.

무음·군더더기 제거는
후보 구간과 전후 맥락을 먼저 보여 준다.

승인된 구간만 삭제하고 한 번에 되돌린다.
VAD와 무음 테스트를 포함한다.

오디오는 다음부터 제공한다.
- 파형.
- 볼륨.
- 음소거.
- 분리.
- 페이드.
- 기본 피크 미터.

이후 추가:
- 대사 구간에서 BGM 자동 낮춤.
- EQ.
- 노이즈 감소.
- 라우드니스 측정·정규화.

임계값 기반 기능을 생성형 AI라고 부르지 않는다.
피크 정규화와 라우드니스 정규화를 구분한다.
기준값은 사용자 설정으로 둔다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
8. 크리에이터 맞춤 제작 기능
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A. AI 클립 보드

각 클립에 다음 정보를 저장한다.
- 장면 번호.
- 생성 도구·모델명.
- 사용자가 입력한 프롬프트.
- 버전.
- 길이와 비율.
- 채택 여부.
- 메모.
- 사용권 확인 상태.

파일에 없는 생성 정보를
자동으로 알아냈다고 주장하지 마라.

같은 장면의 후보 영상을 비교하고
채택한 버전을 타임라인에 교체한다.

교체 시 길이·크롭·오디오 정책을 선택한다.


B. 광고·공모전 모드

사용자가 다음 조건을 직접 설정한다.
- 목표 길이.
- 해상도.
- 화면 비율.
- 파일 크기.
- 필수 문구.
- 금지 요소.

15초·30초·60초·90초는 편의 프리셋이다.
모든 공모전의 공식 규격이라고 표시하지 않는다.

목표 초과와 미입력 정보를 알려 준다.

‘도입/문제/해결/근거/행동유도’ 같은
편집용 마커와 엔드카드를 제공한다.

템플릿은 바꿀 수 있는 시작점이며
영상의 서사를 강제로 고정하지 않는다.


C. 브랜드 키트

다음을 구분한 사용자 편집형 키트를 제공한다.
- 소매점 브랜드.
- 학생 커뮤니티 브랜드.
- 지역 사업 브랜드.
- 개인 공모전.

컬러·설치 폰트·사용자 로고·자막 스타일·엔드카드를 저장한다.

연락처·가격·매장 주소·광고 문구를 임의로 채우지 않는다.


D. 버전 제작

같은 원본에서 다음을 파생 시퀀스로 만든다.
- 세로 버전.
- 가로 버전.
- 도입부 A/B/C 버전.

원본 미디어는 재사용하되
변경이 서로 덮어쓰지 않아야 한다.

여러 버전의 출력은 작업 큐에 넣는다.

조회수 예측·바이럴 점수를 근거 없이 만들지 않는다.


E. 제출 전 검사

확인 항목:
- 출력 길이.
- 해상도.
- 코덱.
- 프레임레이트.
- 파일 크기.
- 오디오 트랙.
- 미디어 누락.
- 자막 안전영역.
- 빈 공간.

검은 화면·장시간 무음은 검토 후보이지
자동 삭제 대상이 아니다.

사용권은 입력된 출처와 확인 상태만 점검한다.
저작권 적법성을 자동 보증하지 않는다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
9. 고급 기능과 미루는 범위
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

기본 엔진 안정화 후 구현한다.

- 수동 도형 마스크.
- 크로마키.
- 블렌드 모드.
- 키프레임 모자이크.
- 검증된 모델/API 기반 객체 추적.
- 인물 배경 제거.
- 자동 리프레임.
- 노출·대비·채도·화이트밸런스.
- LUT·커브·스코프·색상 매칭.
- 비트 검출·장면 검출.
- 전사 검색과 선택형 시각 검색.
- 속도 곡선.
- 고급 오디오.
- 복합 클립·조정 레이어.
- 제한된 FCPXML 교환.

추적에는 손실 상태와 수동 보정 지점을 제공한다.

배경 제거는 머리카락·빠른 움직임·가림 상황에서 검증한다.
Apple의 Magnetic Mask와 동일한 품질을 약속하지 않는다.

색상 매칭도 결과를 미리 보고 수정할 수 있어야 한다.

다음은 초기 범위에서 제외한다.
- 멀티캠.
- RAW 현상.
- HDR 마스터링.
- 360도·공간 영상.
- 3D 모션그래픽.
- 플러그인 마켓.
- 실시간 협업.
- 모바일 앱.

필요해지면 별도 제안과 테스트 계획을 만든다.

생성형 영상·음성 복제·고급 업스케일링을
자체 개발 기본 범위로 넣지 마라.

기존 생성 도구의 결과물을 잘 편집하는 것이 우선이다.

외부 연동은 실제 공개 API·인증·요금·사용 조건을 확인한
서비스만 제공한다.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
10. 파일 안전성·성능·비용
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

원본은 비파괴로 참조한다.

자동 저장은 디바운스와 원자적 쓰기로 처리한다.
버전 백업을 남긴다.

저장 중 종료되더라도
마지막 정상 파일을 복구할 수 있도록 한다.

원본 이동이나 외장 저장장치 분리에 대비해
미디어 재연결을 제공한다.

프록시는 후속 단계에서 추가한다.

원본과 시간·회전·색상 매핑을 보존하고
편집은 프록시, 최종 출력은 원본을 기본으로 한다.

원본이 없을 때 저화질 출력을
원본 품질이라고 표시하지 않는다.

미디어 전체를 메모리에 올리지 않는다.

썸네일·파형·분석 캐시를 재사용한다.
캐시 키에 파일 식별·수정 정보·분석 버전을 포함한다.

속도나 효과 변경 후 오래된 캐시를 쓰지 않는다.

캐시 상한은 설정 가능하게 한다.
원본·프로젝트를 캐시 정리로 지우지 않는다.

16GB 환경에서는 무거운 분석과 출력의 동시 실행을 제한한다.
재생 중에는 백그라운드 작업 우선순위를 낮춘다.

취소 시 하위 작업도 중단하고
미완료 결과를 정상 파일과 구분한다.

4K·AI·실시간 재생 성능은 측정 결과로만 보고한다.

영상·음성·프로젝트의 외부 전송은 기본 비활성화다.

외부 AI 사용 시 표시할 것:
- 업로드하는 내용.
- 예상 비용 또는 산정 불가.
- 비용 한도.
- 사용자 승인.

API 키는 Keychain 등 안전한 저장소를 사용한다.
프로젝트 문서·로그·Git에 넣지 않는다.

외부 AI 없이도 핵심 기능을 유지한다.

FFmpeg·모델·폰트·템플릿의 라이선스와 배포 조건을 기록한다.
FFmpeg는 빌드 옵션에 따라 조건이 달라지므로
임의 바이너리를 무단 묶지 않는다.

원본 삭제, 시스템 보안 해제, 결제,
임의 외부 업로드를 자동화하지 마라.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
11. 개발 단계와 통과 조건
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

모든 기능을 동시에 만들지 마라.

현재 단계의 실제 동작 검증을 통과한 뒤
다음 단계로 진행한다.

단계별 기능 상태를 docs/STATUS.md에 기록한다.


G0 — 편집부터 출력까지 연결

구현:
- 실행 가능한 앱과 새 프로젝트.
- 지원되는 SDR H.264 영상·PNG·오디오 입력.
- 1080p/30fps 프로젝트.
- 메인 클립 배치·선택·분할·트림·순서 변경.
- 한국어 제목 1개 이상.
- PNG 오버레이.
- BGM과 기본 볼륨.
- 합성된 타임라인 재생.
- 실제 H.264/AAC MP4 출력.
- 프로젝트 저장·재열기.
- 핵심 편집 undo/redo.
- 오류·취소 처리.

통과 조건:
아래의 15초 테스트 영상을 실제 출력하고
저장 후 재현한다.


G1 — 일상 편집기

구현:
- 다중 트랙 조작.
- 스냅·리플 편집.
- 키프레임·일정 배속·기본 전환.
- 수동 자막·SRT.
- 오디오 파형·페이드.
- 비율별 파생 버전.
- 자동 저장 복구.
- 미디어 재연결.
- 프록시.
- 검증된 추가 입력 형식.

4K 등 추가 출력 프로필은
실제 기기·파일 테스트를 통과한 항목만 활성화한다.

통과 조건:
60초 광고와 10분 영상을
편집·저장·재열기·출력하는 회귀 테스트.


G2 — 한국어 자동화와 개인 워크플로

구현:
- 로컬 자동 자막.
- 전사 검색·텍스트 편집.
- 무음 후보 검토.
- 브랜드 키트.
- AI 클립 보드.
- 공모전 규격.
- A/B 버전.
- 출력 큐.
- 제출 전 검사.

통과 조건:
모델 설치 후 핵심 흐름이 오프라인에서 작동하고
자동 수정 전체를 되돌릴 수 있음.


G3 — 고급 영상 도구

구현:
- 마스킹·추적·크로마키.
- 고급 색보정.
- 속도 곡선.
- 비트 검출·장면 검출.

정확도·성능·지원 범위·실패 사례를 별도로 공개한다.

통과 조건:
미리보기/출력 일치 테스트와
기능별 실제 미디어 테스트.


G4 — 선택형 외부 AI·교환·배포

필요성이 확인된 API 연동,
제한된 프로젝트 교환, 배포 준비를 진행한다.

AI 명령은 허용된 편집 명령의
구조화된 제안으로 변환한다.

적용 전에 변경 내용을 보여 준다.
LLM에 임의 코드·셸·파일 삭제 권한을 주지 않는다.

FCPXML 등은 명시된 부분집합만 지원한다.
미지원 효과·구조를 보고한다.
무손실 왕복을 검증 없이 주장하지 마라.


이번 요청의 실행 범위:

환경 점검과 현재 미통과 게이트 하나다.

새 프로젝트라면 G0를 실제 구현·검증한다.
이미 G0가 있으면 회귀 테스트 후 다음 게이트로 진행한다.

범위 제한을 이유로 문서나 빈 뼈대만 만들지 마라.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━
12. 테스트와 첫 결과물
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

네트워크와 유료 소재 없이
재현 가능한 테스트 픽스처를 생성한다.

직접 생성한 색상·프레임 번호 영상,
PNG, 테스트 오디오를 사용한다.

개인 자료를 저장소에 넣지 않는다.

첫 사용자 흐름:

1. 1080×1920, 30fps 프로젝트를 만든다.

2. 5초짜리 영상 3개를 가져와
   각각 4초로 트림한다.

3. 3초짜리 이미지 엔드카드를 붙여
   총 15초로 만든다.

4. 한국어 제목 ‘나의 첫 영상’과
   별도 PNG 오버레이를 넣는다.

5. BGM을 배치하고 볼륨을 낮춘다.

6. 저장 → 앱 종료 → 재열기 →
   재생 → MP4 출력까지 수행한다.


필수 검증:

- 현재 단계에서 구현한 시간 계산과 편집 명령.
- undo/redo.
- 프로젝트 직렬화 왕복.
- 1080×1920 / 30fps / 15초.
- 영상 450프레임 목표.
- 컨테이너·오디오 패딩은 별도로 해석.

출력 파일을 다시 디코딩하여
제목·오버레이·장면 순서·오디오가
실제 포함됐는지 확인한다.

대표 타임스탬프의 미리보기와 출력 이미지를 비교한다.

손실 압축 오차를 고려한 임계값과
육안 점검을 함께 기록한다.

오류·경계 테스트:
- 한국어 파일명.
- 띄어쓰기 경로.
- 같은 이름 파일.
- 한글 자막.
- 세로 회전 메타데이터.
- 오디오 없는 영상.
- 잘못된 파일.
- 출력 경로 오류.
- 저장공간 부족.
- 작업 취소.
- 미디어 누락.

후속 단계에서 추가:
VFR, 29.97fps, 4K HEVC, HDR,
외장 저장장치 분리.

실행하지 않은 테스트는
‘통과’가 아니라 ‘미실행’으로 표시한다.

성능은 기기·OS·입력 코덱·클립 수·길이·출력 설정을
함께 기록한다.

측정 항목:
첫 프레임 시간, 탐색 지연, 재생 드롭,
피크 메모리, 출력 시간.

근거 없는 ‘완벽한 최적화’ 표현을 쓰지 마라.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━

재현 가능한 빌드 구성을 포함한다.

Xcode GUI에서 수동으로 파일 수십 개를
등록하게 만들지 마라.

실제 저장소에 맞는
빌드·테스트·실행 명령을 제공한다.

필요한 환경 설정은 최소화하고
설치 여부를 먼저 확인한다.

최종 응답에는 다음을 포함한다.

- 현재 게이트.
- 구현된 기능.
- 변경 파일.
- 실행 방법.
- 실제 테스트 결과.
- 출력 파일 경로.
- 미구현·미검증 항목.
- 다음 게이트 진입 조건.

앱 스크린샷은 렌더링 결과 검증의 대체물이 아니다.

실행 환경 제한으로 막히면
정확한 명령과 오류, 완료한 부분,
사용자가 수행할 검증을 남긴다.

구현되지 않은 기능을 포괄적으로 ‘완성’이라고 부르지 마라.

먼저 저장소를 확인하고
실제 편집 가능한 최소 흐름을 구현하라.
