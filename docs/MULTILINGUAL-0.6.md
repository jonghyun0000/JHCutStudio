# 0.6 — 한국어·일본어·영어 자동 자막과 번역

## 사용

1. 앱에서 음성이 있는 지원 영상을 가져온다. 기본값은 **자동 감지·자동 자막·한국어 번역 켜짐**이다. 가져온 영상은 메인 영상 트랙의 마지막에 순서대로 배치된다.
2. 기존 Whisper base 다국어 모델이 음성 언어를 감지하고 원문 자막을 만든다. 자막 탭의 ‘자동 자막’에서 감지 결과를 확인한다.
3. 한국어 원문은 그대로 표시한다. 일본어·영어 원문은 한국어로 번역해 별도 트랙에 표시한다. 원문 트랙은 숨긴 상태로 보존한다.
4. **자막 → 자동 자막 → 자막 번역 설정**에서 한국어·일본어·영어를 선택하고 ‘원문 자막 전체 번역’을 누른다. 원문 언어를 잘못 판단했다면 직접 지정한다.
5. ‘원문·번역을 함께 표시’를 켜고 번역하면 두 문구가 한 자막에 함께 표시된다. ‘원문 자막 표시’는 번역을 지우지 않고 원문으로 전환한다.
6. 자막 목록에서 문구를 교정한다. 재번역 시 직접 수정한 번역을 보존한다. 이미 수정한 번역에 새로운 번역/동시 표시를 적용하려면 해당 번역 클립을 삭제한 뒤 다시 번역한다.
7. 번역 설정의 용어집에 `원문=번역`을 한 줄씩 입력하면 번역 결과의 고유명사·브랜드명을 일관되게 교체한다.
8. SRT 저장 범위는 기본적으로 **표시 중인 자막**이다. ‘원문 자막’, ‘번역 자막’도 고를 수 있다. ‘번역 자막’ 범위는 보관 중인 여러 언어의 숨긴 번역도 포함한다. 한 언어만 출력하려면 그 언어를 표시하고 기본 범위로 저장한다.

기존 타임라인은 음성이 있는 클립을 선택한 뒤 자동 자막을 생성한다. 여러 클립을 동시에 선택할 수 있다. SRT로 가져온 원문도 전체 번역할 수 있다. 자동 자막과 자동 번역 스위치는 각각 끌 수 있고, 설정은 현재 앱 실행 동안 유지된다.

## 처리와 보존

- 원본 동영상은 읽기만 한다. 별도의 클라우드 계정이나 번역 API 키가 필요하지 않다.
- 음성 인식은 로컬 whisper.cpp와 이미 승인된 base 모델을 사용한다. 추가 small 모델은 자동 설치하지 않는다.
- 번역은 Apple Translation의 **설치된 모델만** 사용한다. macOS 26.4 이상에서는 설치된 고품질 모델을 우선 선택하고 저지연 모델을 대체 경로로 사용한다. 설치 상태 확인과 번역에 같은 모델 전략을 적용한다.
- 이 앱의 번역 기능은 macOS 26 이상이 필요하다. macOS 14/15에서는 원문 자동 자막 기능을 계속 쓸 수 있다. 번역 언어팩이 없으면 원문을 유지하고 설치 위치를 안내한다. 앱이 임의로 다운로드하지 않는다.
- Apple은 번역 문구를 포함하지 않는 API 사용/성능 메타데이터를 수집할 수 있다. [TranslationSession 공식 안내](https://developer.apple.com/documentation/translation/translationsession).
- 번역 클립은 원문, 원문 언어, 목표 언어와 원본 영상의 연결 시간을 저장한다. 영상 이동/트림/배속 등의 연결 편집을 따른다.
- 번역 실패·취소·편집 중 문서 변경 시 번역 결과를 부분 적용하지 않는다. 원문과 이전 번역을 보존한다. 번역 적용은 실행취소 한 단계다. 영상 가져오기, 타임라인 배치, 원문 생성은 각각 별도 실행취소 단계다.
- 새 문서 필드를 모르는 구버전은 열기를 거부할 수 있다. 0.6에서 저장한 프로젝트를 편집할 때는 0.6 이상을 사용한다.

## 정확한 지원 범위

Whisper는 클립별 대표 음성을 감지하고, 생성된 각 문장은 텍스트 언어 분석으로 메타데이터를 보정한다. 따라서 짧은 혼합 언어 문장을 번역 그룹으로 나눌 수 있지만, 음성 자체를 문장마다 다시 판정하는 화자·언어 분리 기능은 아직 없다. 짧은 대사·음악·잡음·고유명사는 오인식할 수 있다. 번역은 인식된 문구를 입력으로 사용하므로 잘못 인식된 원문을 먼저 교정한 뒤 재번역하는 편이 좋다.

번역은 프로젝트의 원문 자막 전체를 대상으로 한다. 다른 용도의 제목도 같은 title 트랙 모델을 사용하므로 원문 목록에 포함될 수 있다. 잠긴 자막 트랙, 한 트랙에 원문과 번역을 섞어 옮긴 상태에서는 안전하게 중단하고 정리 방법을 안내한다. 원문과 번역을 별도 트랙으로 유지한다.

이번 검증은 설치된 base와 Apple 번역 모델을 사용한 짧은 세 언어의 합성 음성 및 실제 번역 실행이다. 잡음/사투리/장시간 대화의 정답 기반 정확도 평가나 언어 전문가의 번역 품질 인증은 아니다.

## 재현

`bash Scripts/build.sh` 후 `bash Scripts/test-multilingual.sh <새 결과 폴더>`를 실행한다. base 모델, 설치된 Apple 번역 모델, macOS 26 이상, Yuna/Kyoko/Samantha 음성이 필요하다. 음성/모델 다운로드는 검사 스크립트가 수행하지 않는다. 생성된 `.jhcut`, `.srt`, `.mp4`, 프레임 이미지, `checks.json`이 결과 폴더에 남는다. 일본어 시험 음성은 짧은 두 문장이다.
