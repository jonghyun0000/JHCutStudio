# Shared G0 implementation contract

Core module: JHCutCore. All cross-target declarations public, explicit public initializers. Swift language mode 5, macOS 14 minimum, no dependencies. Sources grouped by responsibility, single core target.

Domain interface (domain agent owns):
- `MediaTime: Codable, Hashable, Comparable, Sendable` with `value: Int64`, `timescale: Int32`; `init(_ value:Int64, _ timescale:Int32 = 600)`, `init(seconds:Double)`, `seconds:Double`, `static zero`, + and - operators, `.cmTime` may be extension in MediaEngine. Rational arithmetic, half-open ranges. `FrameRate(numerator:Int32 = 30, denominator:Int32 = 1)`, `time(forFrame:Int64)`.
- `MediaKind: String, Codable` cases video, image, audio. `MediaAsset: Codable, Identifiable` properties `id:UUID`, `name:String`, `path:String` (absolute source fallback), `relativePath:String?`, `bookmark:Data?`, `kind:MediaKind`, `duration:MediaTime`, `width:Int`, `height:Int`, `hasAudio:Bool`, `codec:String`, `colorInfo:String`, `supported:Bool`, `issue:String?`. Defaults on initializer except name/path/kind. `resolvedURL(relativeTo:URL?) -> URL` resolving relative parent document folder then bookmark then path.
- `TrackKind: String, Codable` cases video, overlay, title, audio. `Track: Identifiable, Codable` id/name/kind/clips:[Clip]/isMuted:Bool/isHidden:Bool/isLocked:Bool. `Clip` id/name/assetID:UUID?/start:MediaTime/sourceStart:MediaTime/duration:MediaTime/volume:Double/transform:ClipTransform/title:Title?. `ClipTransform` x/y:Double=0 (pixel offsets from canvas center), scale:Double=1, rotation:Double=0 degrees, opacity:Double=1, fill:Bool=false. `Title` text:String/fontName:String="AppleSDGothicNeo-Bold"/fontSize:Double=76/colorHex:String="FFFFFF"/x:Double=0.5/y:Double=0.8 (normalized, y measured from BOTTOM); text uses own title x/y, transform may also apply. Media images use ClipTransform.
- `Sequence` id/name/width=1080/height=1920/frameRate:FrameRate/colorSpace="Rec.709"/tracks:[Track], `duration:MediaTime` computed max end; initial default four tracks main video, overlay, title, audio.
- `Project` schemaVersion=1/id/name/assets:[MediaAsset]/sequence:Sequence. `init(name:String = "새 프로젝트")`.
- `EditCommand` cases addAsset(MediaAsset), addClip(trackID:UUID, clip:Clip), updateClip(trackID:UUID, clip:Clip), split(trackID:UUID, clipID:UUID, at:MediaTime), delete(trackID:UUID, clipID:UUID, ripple:Bool), move(trackID:UUID, clipID:UUID, to:MediaTime), reorder(trackID:UUID, clipID:UUID, direction:Int), updateTrack(Track), rename(String). `EditorHistory` init(project:Project), project read, canUndo/canRedo; mutating `apply(_:) throws`, undo(), redo(). Validation atomic. `ProjectValidator.validate(_:) throws`.
- `ProjectStore.save(_:to:) throws`, `load(from:) throws -> Project`. Atomic write plus prior-version backup, relative media references, schema validation. No silent fallback recovery. `ProjectStore.recover(from:)` optional explicit API.

Media engine interface (engine agent owns):
- `MediaImporter.inspect(url:URL) async throws -> MediaAsset`; rejects/flags HDR, non-H264 video for G0, accepts PNG and decodable audio, rotation metadata. Do not re-label unknown HDR as SDR.
- `RenderPlan` built through `TimelineRenderer.build(project:Project, documentURL:URL? = nil) async throws -> RenderPlan`. Plan has `composition:AVMutableComposition`, `videoComposition:AVMutableVideoComposition`, `audioMix:AVMutableAudioMix`; `makePlayerItem() -> AVPlayerItem`. One compositor for preview & output; title/PNG are in actual pixels. Black carrier needed for image-only and gaps. `TimelineRenderer` enum/static implementation okay.
- `ExportJob` public class, `init()`, `cancel()`, `export(plan:RenderPlan, to:URL, progress:@escaping (Double)->Void) async throws`; explicit H264/AAC MP4 and no overwrite existing, temp .partial then atomic destination move. Can use AVAssetReader/Writer to guarantee codec/count and audio. Export checks disk/write errors and cancellation.

Validation agent owns Validation/, Tests/MediaIntegrationTests.swift if needed. Domain agent owns remaining Tests. Validation can use renderer API above and create fixtures using AVAssetWriter; use no ffmpeg dependency. CLI `JHCutValidate [outputDirectory]` creates three 5-sec color/frame-index H264 videos, Korean PNGs/end card/BGM, builds 15sec project via edit commands, saves and reloads then exports. Decodes and counts video/audio samples, saves preview/export PNGs, measures differences and reports JSON/Markdown. Test cancellation/missing files/invalid input/output failures where possible. May add modes --verify project path or --fixtures if useful. All generated work in user-selected output folder.

Root owns App/, Package.swift, Scripts/, docs/, README. Never write another agent's files without coordination. Notify cross-agent API deviations promptly.
