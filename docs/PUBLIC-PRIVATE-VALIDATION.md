# Public and private validation lanes

The [public workflow](../.github/workflows/public-generated.yml) builds the full app and executes generated domain, compatibility, productivity and UI localization probes. It does not need private recordings, an installed Whisper model, human reference transcripts or Apple translation packs. The [main hosted run](https://github.com/jonghyun0000/JHCutStudio/actions/runs/38773524663) completed successfully for `5f77ae1bb30021f7317bd5b32955fb72c9a4af28`: full app build and 138 generated checks, with Python 10/0 and workspace 16/0 separately. See the dated [scope and limits](RELEASE-READINESS.md#hosted-ci-evidence); [Actions](https://github.com/jonghyun0000/JHCutStudio/actions/workflows/public-generated.yml) shows later results. Only verification indices and logs are retained as diagnostics, not generated outputs, binaries or private/model inputs.

The default runner additionally registers feature-specific and private real-video suites. Those tests are kept as source to preserve acceptance requirements. References, camera videos, transcripts, provenance directories and result artifacts are deliberately absent from public source. Fixed filenames in private probes are a local evaluation contract; they are not public sample media and arbitrary substitute footage cannot reproduce the same accuracy or performance claim.

For a separately authorized private evaluation, prepare a reviewed dataset/reference manifest, set explicit local paths and use immutable copies. `Scripts/real-copies.sh` requires `JHCUT_IPHONE_DIR` instead of guessing a maintainer's disk. Never upload private media or entire run directories to an issue or CI artifact. To add a shareable regression, create a small generated or explicitly redistributable fixture and state what it proves.

The runner expects a genuine Git checkout and creates fresh evidence under Artifacts. The published repository has Git history; a downloaded source archive does not. Run the verifier from a standalone checkout with its own valid HEAD. The runner rejects source archives, repositories without HEAD and nested copies that would inherit an unrelated parent repository before creating a run or building. A source archive can still use `Scripts/build.sh`; it cannot borrow a parent Git identity for source-bound verification.

A development build, code existence, matching copied SHA, selected suite success and human/native/other-Mac acceptance are separate properties. The [35 requirements](GOAL-REQUIREMENTS-2026-10-11.md) and [original neutral specification](ORIGINAL-PRODUCT-SPEC-2026-10-11.txt) remain the coverage checklist.
