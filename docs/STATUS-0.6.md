# 구현·검증 상태 — 2026-09-25 / 0.6.0 (7)

한국어·일본어·영어 영상 가져오기 → 언어 감지 → 원문 자막 → 선택 언어 번역을 추가했다. 기본 목표 언어는 한국어다. [사용법과 제한](MULTILINGUAL-0.6.md)을 참고한다. 기존 34개 개선의 범위·256개 검사 기록은 [0.5 상태](STATUS-0.5.md)에 보존했으며, 이번 기능 추가로 기존 미완료 항목까지 완료했다고 계산하지 않는다.

허용된 `/Volumes/T7/아이폰/동영상`에서 `IMG_0140.mov`, `IMG_0047.mov`, `IMG_9211.mov`의 원본을 수정하지 않고 각 30초 구간을 자동 평가했다. 결과는 `Artifacts/Multilingual-0.6/RealIPhone/report.json`과 `real-iphone.log`에 있다. 감지 언어는 각각 영어, 한국어, 한국어였고 자막 타임코드는 세 영상 모두 유효했다. 처리 시간은 30초 구간당 0.86~2.66초(실시간 대비 0.029~0.089배)였다. `captionedSeconds`와 `captionCoverage`는 Whisper가 자막을 낸 시간의 양이며 실제 음성 정답 커버리지가 아니다. 원본 대본이 없어 CER은 산출하지 않았다. 같은 이름의 `.txt` 대본을 옆에 두면 probe가 정규화 문자 CER을 추가 기록한다.

## 실제 실행 결과

Mac의 Yuna/Kyoko/Samantha 음성으로 만든 알려진 대사를 영상 파일에 넣어 검사했다. 한국어 약 11초, 일본어 약 4.5초, 영어 약 10.3초다. 세 영상을 한 번에 가져왔을 때 원문 10개와 별도 한국어 자막 10개가 생성됐다. 감지된 언어는 각각 ko/ja/en으로 맞았다.

Apple 번역 엔진으로 ko→ja, ko→en, ja→ko, ja→en, en→ko, en→ja를 실제 실행했다. 33문장 배치에서 32문장 단위 처리 경계와 응답 순서를 확인했다. 원문·번역 병기, 목표 언어 변경, 수동 수정 보존, 실행취소, 저장/재열기, 영상 이동에 따른 연결 자막 이동도 확인했다. 실패·취소·문서 변경 검사는 주입된 실패 응답을 사용한 별도 검사이며 실제 번역 성공 검사와 구분했다.

- 결과 프로젝트: `Multilingual.jhcut`
- 한국어 SRT: `translated-ko.srt`
- 영상: `translated-output-03406B08.mp4` (약 26초, 오디오 포함)
- 일본어를 한국어로 번역해 출력한 프레임: `translated-frame.png`

GUI에서도 파일 선택창으로 `ja-speech.mp4`를 가져왔다. ‘감지된 음성: 일본어’, 원문 트랙 숨김, 한국어 번역 트랙 표시와 미리보기 자막을 확인했다. 결과는 `Japanese-Import-GUI.jhcut`에 저장했다. 프로그램 내부 모델 검증만으로 GUI 통과라고 계산하지 않았다.

## 이번에 함께 수정한 오류

- Whisper 실행 요청값 `auto`를 감지 결과로 저장하던 문제: JSON의 실제 `result.language`를 읽는다.
- Apple 번역 기본 전략이 설치된 모델과 다른 경우: 설치 상태 확인과 실행 모두 같은 전략을 사용한다. 이 Mac에서는 고품질 모델로 성공했다.
- 숨긴 원문 자막 재생성 시 전체 트랙 갱신이 새 자막을 지울 수 있던 순서 문제: 표시 상태를 먼저 변경하고 새 자막 편집을 적용한다.
- 숨긴 원문/번역 때문에 SRT와 겹침 경고가 중복되던 문제: SRT 기본 범위 및 겹침 경고를 표시 중인 자막 기준으로 처리한다.

## 제한

- 언어는 클립별 대표 언어를 감지한다. 한 클립 내 문장별 언어 전환이나 화자 분리는 미구현이다.
- 합성 음성의 기능 검증이다. 실사 잡음·사투리·고유명사의 정답 기반 인식 정확도나 전문 번역 품질 점수는 산정하지 않았다.
- 이 앱의 번역은 macOS 26 이상과 설치된 Apple 번역 모델을 요구한다. macOS 14/15에서는 원문 자동 자막을 사용할 수 있다. 다른 OS 버전/기기에서 직접 실행 검증하지 않았다.
- 추가 모델을 다운로드하지 않았다. 승인된 Whisper base와 이미 설치된 Apple 번역 모델만 사용했다.
- 0.5에 남아 있던 공증, 다른 Mac 배포, 연속 장시간 GUI 재생 등의 제한은 그대로다.
