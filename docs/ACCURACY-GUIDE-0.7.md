# 실사 영상 정확도 측정 — 대본 작성 안내

CER/WER은 **사람이 직접 듣고 쓴 대본**이 있어야 의미가 있습니다. Whisper 초안을 그대로 쓰거나 다른 인식기로 만든 대본은 인식기끼리 비교하는 것이라 정확도가 아닙니다. 그래서 앱과 스크립트는 초안과 똑같은 대본을 거부합니다.

## 준비된 구간 (원본의 읽기 전용 복사본에서 잘라냄)

`Artifacts/Upgrade-0.7/Accuracy/`

| 구간 | 내용 | 들을 파일 |
|---|---|---|
| `IMG_0047-660-780` | 야구장, 중계 해설 + 옆 사람 대화 (11:00~13:00) | `IMG_0047-660-780.listen.m4a` |
| `IMG_9211-480-600` | 일상 대화, 뒤에 음악·노래 (8:00~10:00) | `IMG_9211-480-600.listen.m4a` |

각 구간 폴더에는 비교용 `whisper-full.srt`(전체 인식)·`whisper-skip.srt`(비음성 건너뛰기)와 `draft-from-whisper.srt`(수정용 초안)가 있습니다.

## 작성 방법 (둘 중 하나)

**A. 처음부터 받아쓰기 (권장 — 초안에 끌려가지 않음)**
- 파일 이름: `IMG_9211-480-600.reference.txt` (UTF-8)
- 들리는 말을 한 줄에 한 문장씩. 시간은 쓰지 않습니다.
- 결과: CER, WER, 누락/추가 문장. (시간 오차는 계산되지 않음)

**B. 초안 고치기 (시간 오차까지 측정)**
- `draft-from-whisper.srt`를 복사해 `IMG_9211-480-600.reference.srt`로 저장하고, 들으면서 **모든 줄을** 확인해 고칩니다.
- 실제로 말하지 않은 줄(예: `[믹뚙뚙뚙]`, `[몇일이 없음]`)은 지우고, 빠진 말은 시간과 함께 새 줄로 넣습니다.
- 시간은 **원본 영상 기준**입니다(`00:08:00,000` = 480초). 잘라낸 파일의 0초가 아닙니다.
- 주의: 초안의 틀린 말을 “비슷하니까” 그대로 두면 오류가 적게 계산됩니다.

## 규칙

- 대사만 씁니다. 음악 가사·노래, 웃음·환호·효과음은 쓰지 않습니다(자동 자막의 목표가 대사이기 때문).
- 말한 그대로, 표준 맞춤법으로. 문장부호와 띄어쓰기는 점수에 영향이 없습니다(평가 시 정규화).
- 알아듣기 어려운 부분은 가장 그럴듯한 말을 쓰거나 비워 두고, `[?]` 같은 표시는 넣지 마세요(글자로 계산됩니다). 비운 곳은 따로 메모해 주세요.
- 두 사람이 겹쳐 말하면 들리는 순서대로 모두 씁니다.

## 측정

```bash

```

대본이 있는 구간만 채점하며, 전체 인식과 비음성 건너뛰기를 각각 `*.evaluation-full.md|json`, `*.evaluation-skip.md|json`으로 저장하고 `summary.json`에 모읍니다. 대본이 없으면 “평가 불가”, 초안과 똑같으면 “평가 거부”, 초안과 2% 미만으로 다르면 경고합니다. 원본 영상은 읽지 않고 복사본만 쓰며, 실행 전후 원본 해시를 확인합니다.
