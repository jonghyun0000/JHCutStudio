# JH CUT Studio 0.3 — 편집 생산성과 미디어 호환성

0.2의 내부 평가 62점에서 80점 이상을 목표로 약점 38개를 기록하고 핵심 기능을 구현했다. 80점 달성을 선언하지 않는다. 전체 약점은 [AUDIT-0.3.md](AUDIT-0.3.md), 세부 재현 근거는 도메인·엔진·생산성 감사 문서에 있다.

## 구현

- SDR H.264 / HEVC / ProRes 422 계열 영상과 PNG / JPEG / HEIC 사진. EXIF 회전·미러와 색 정보 점검. HDR·Log의 SDR 변환은 아직 없다.
- 프록시 생성·재사용·취소·캐시 정리. 최대 1280×720, 2GB 캐시. 원본 변경 시 식별자를 다시 확인한다. 출력기는 프록시 계획을 거부하고, 앱은 원본으로 별도 출력 계획을 만든다.
- 클립 삽입·덮어쓰기, 영상 오디오 분리, 다른 트랙 이동, 트랙 추가·이름·순서·빈 트랙 삭제. 삽입·리플은 현재 영상 트랙만 변경한다.
- 키프레임·페이드가 있는 클립의 분할·트림. 출력 프레임 시점의 값을 보존하도록 표본화하며 프레임 사이 곡선은 근사한다. 최대 36,000개 키 제한.
- 실제 원본 오디오의 피크·RMS·클리핑 경계 샘플·무음 후보 분석. 선택 구간 및 배속 시간 매핑. 피크 정규화는 목표 -1dBFS, 증폭 상한 +12dB이며 LUFS/리미터는 아니다.
- 반대 위상 스테레오 파형 상쇄 수정. 음성 인식 추출도 채널 상쇄를 피하도록 일정한 고에너지 채널을 선택한다.
- 자막 병합·전체 시간 이동, UTF-8 / UTF-16 / CP949 SRT 읽기, 줄 잘림·시간 중첩 안내, 80% 안전 영역 미리보기.
- 공식 whisper.cpp 실행 파일과 한국어 다국어 모델 설치·체크섬·취소·오류 처리를 연결했다. 모델은 앱에 포함하지 않는다. 사용자가 출처·라이선스·해시·용량을 확인하고 설치에 동의해야 한다. 설치 후 선택한 음성 클립의 자막을 새 트랙에 추가한다.
- 프로젝트와 모든 원본 수집: 스트리밍 복사·SHA-256 검증·동일 내용 중복 제거·파생 시퀀스 보존·취소 정리. 새 폴더에만 확정한다. ExFAT은 폴더가 작업 중 보일 수 있으며 문서를 마지막에 기록하므로 완료 알림 이후 연다.
- 여러 미디어 가져오기를 한 번의 Undo로 처리, 취소·진행률, 파일 작업 중 종료 보호. 미디어 검색, 속성 접기, 타임라인 헤드 자동 스크롤과 세로 트랙 이름 동기화.
- H.264 출력 품질 4 / 8 / 16Mbps. AAC 192kbps, SDR Rec.709, 30fps, 최대 1920 캔버스 제한은 유지한다.
- 알 수 없는 최신 문서 편집 필드를 조용히 지우지 않고 읽기 거부한다.
- 속성 패널의 슬라이더가 드래그하는 동안 미리보기에 바로 반영된다. 드래그 한 번은 실행취소 1단계다. 토글·스테퍼·피커는 값이 바뀌는 즉시 적용되고, 숫자 입력은 Return 또는 ‘입력한 숫자 적용’을 그대로 쓴다.
- 편집할 때마다 타임라인 전체 길이의 검은 carrier를 다시 인코딩하던 동작을 캐시·반복 삽입으로 바꾸고, 클립마다 만들던 컴포지션 트랙을 겹침 깊이 기준으로 패킹했다. 10분·300컷 타임라인의 조합 재구축이 11.510초에서 0.070초가 됐다.

## 직접 사용하는 순서

1. 미디어를 가져오고, 선택 후 타임라인 끝 추가 또는 ‘여기에 삽입 / 덮어쓰기’를 사용한다. 클립을 선택하면 속성의 노출·대비·채도·크롭·불투명도·볼륨·페이드 슬라이더를 드래그하면서 결과를 바로 볼 수 있다.
2. 프로젝트 속성의 ‘프록시 미리보기’에서 영상 프록시를 생성한다.
3. 소리가 있는 클립을 선택해 ‘오디오 분석’을 실행한다. 무음 후보 클릭은 해당 위치로 이동하며 자동 삭제하지 않는다.
4. 자막 탭의 자동 자막 영역에서 모델을 설치한 뒤 ‘선택 클립에서 한국어 인식’을 실행한다. 결과를 검토하고 수정한다.
5. ‘프로젝트와 원본 모으기’로 다른 컴퓨터에 옮길 사본을 만들 수 있다.
6. 프로젝트 속성의 출력 품질을 고른 후 MP4 출력한다. 프록시 켜짐 여부와 무관하게 원본 영상으로 출력한다.

## 검증 범위와 남은 과제

최종 자동 검사216개가 통과했다. 실제 앱의 분석·정규화 Undo·효과 트림·프록시·출력·T7 원본 수집과 재열기를 확인했다. 세부 결과와 한계는 [STATUS](STATUS.md)에 기록했다. 로컬 합성 자료 통과가 모든 카메라·장시간 실사·외장 드라이브·Intel Mac의 검증을 대신하지 않는다. 한국어 모델의 실제 인식은 별도 설치 승인이 필요하며, 승인 전에는 정확도나 자막 생성 완료를 주장하지 않는다.

조합 재구축 비용은 측정해서 줄였지만, 이는 실사 장시간 편집의 안정성 검증을 대신하지 않는다. 80점 이상을 평가하려면 실제 한국어 대사 정확도, 긴 실사 다중 트랙 편집, 4K/다중 프레임레이트, HDR 처리, 연결 클립 동기 편집, 최종 믹스 음량 제어를 우선 검증·개선해야 한다. 고급 마스킹·추적·멀티캠·외부 편집 도구 연동도 상용 앱과 큰 격차로 남아 있다.
