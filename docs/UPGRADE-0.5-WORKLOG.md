## 사용법

- 타임라인의 원본을 이동/자르기하면 연결된 자동 자막·분리 대사가 따라간다. 독립 이동은 속성의 연결 해제부터 사용한다.
- 자막 패널에서 모델·언어·대사 채널·전문용어를 선택한다. base는 설치되어 있다. small은 설치 동의 후에만 다운로드한다. 생성 후 문구를 반드시 교정한다.
- 배경음 클립을 선택하고 오디오 도구에서 자동 감쇠 강도·복귀 시간을 정한 뒤 적용한다. 대사 판단은 현재 자막 구간 기준이다.
- 프로젝트 속성의 ‘믹스 완성 버전 만들기’는 별도 버전을 만든다. 원래 버전은 아래 버전 목록에 남는다. 이후 편집을 바꾸면 원래 버전에서 믹스를 다시 만든다.
- 프로젝트 속성에서 파일 형식과 출력 범위를 고르고 출력 대기열에 추가한다. 완료/실패 기록은 ‘최근 출력 기록’에서 확인한다. 큐 대기 항목은 앱 종료 시 복원되지 않는다.
- HDR 원본은 ‘HDR → SDR 사본 가져오기’로 변환한다. 원본은 바뀌지 않는다. Log/색 정보가 없는 원본은 거부한다.
- 누락 파일은 ‘폴더에서 누락 원본 찾기’로 동일한 원본만 자동 연결한다. 미확인/다른 파일은 개별 재연결에서 명시적으로 선택한다.
- 0.5 문서는 추가 필드가 있어 0.3/0.4에서 거부될 수 있다. 이전 작업을 덮어쓰기 전에 다른 이름으로 보관하는 것이 안전하다.

## 작업 범위 밖으로 남긴 것

사용자의 T7 원본은 읽기만 했고 외부 업로드하지 않았다. 다른 앱의 유료 소스를 복사하지 않았으며 이번 작업에서 새 외부 B-roll을 수집한 것으로 계산하지 않았다. small 모델 설치·실사 CER·공증·다른 기기/실사용자 평가는 완료 증거가 없어 완료 처리하지 않았다.
