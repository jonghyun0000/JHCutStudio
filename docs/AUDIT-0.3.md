## 이번 결과

38개 중 30개 항목에 코드와 화면을 추가·수정했다. 이후 점검에서 찾은 39–41을 추가로 수정했다. 나머지는 HDR 변환, 4K, 다중 출력 fps, 실제 한국어 모델 인식, 연결 클립, 최종 믹스 LUFS/리미터, 장시간 실사 성능, 전문 고급 기능이다. 구현된 기능도 아래 제약이 있다.

- 프록시 재생이 원본의 모든 카메라/VFR 특성을 지원한다는 의미는 아니다. 검증한 파일·시점·샘플 시간은 호환성 보고서에 명시한다.
- 효과 보존 트림은 출력 프레임 기준 표본화다. 연속 곡선의 완전 동일성을 보장하지 않는다.
- 무음은 분석 후보이며 자동으로 영상을 삭제하지 않는다. 피크 정규화는 믹스 전체의 LUFS 정규화가 아니다.
- 자막 병합은 스타일·효과가 호환되는 자막에 한한다. 자동 인식은 설치 승인과 실제 인식 검증 전까지 완료 기능 점수에 포함하지 않는다.
- 39·40의 수치는 합성 fixture의 단일 영상 트랙 측정이다. 실사 소재·다중 트랙·프록시 조합에서 같은 값이 나온다는 뜻이 아니다. 측정 조건과 전후 비교는 [엔진 감사](AUDIT-ENGINE-0.3.md)에 있다.
- 41의 라이브 미리보기는 슬라이더·토글·스테퍼·피커에 적용된다. 숫자 입력 필드는 부분 입력이 적용되지 않도록 Return 또는 ‘입력한 숫자 적용’을 유지한다. 자막 본문 TextEditor도 아직 버튼 경로다.
- 41의 모델 계층은 헤드리스 검사 14개로 확인했으나 `ClipInspector`의 SwiftUI 본문은 컴파일과 코드 검토만 거쳤다. 실제 GUI 드래그 확인은 남아 있다.
- 모델 설치 승인 질문은 최초 사용자 명세의 ‘출처·라이선스·체크섬·필요 공간 표시 및 사용자 승인 후 설치’를 따랐다. 응답 없이 다운로드하지 않았다.
