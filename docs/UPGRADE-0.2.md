# 0.2 콘텐츠·편집 업그레이드

사용자 요청: 효과음·배경음·편집 소스·자막 스타일을 추가하고, 기존 35/100점 수준에서 최소 60점 수준을 목표로 실사용 기능을 보강한다. 점수는 기능과 검증 증거에 대한 개발자 평가이며 공인 벤치마크가 아니다.

## 실제 포함한 자료

- 효과음 112개: Kenney Interface Sounds CC0 100개 + 직접 제작 12개.
- 배경음 10곡: 개별 저작자 CC0 공개곡 8개 + 직접 제작 2개.
- 투명 오버레이 16개, 배경 8개, 텍스처 8개: 직접 제작 PNG.
- 자막·타이틀 스타일 24종: 직접 설계한 글꼴/색/테두리/배경/배치 프리셋. 별도 폰트 파일은 배포하지 않고 설치된 Apple 시스템 폰트를 참조한다.
- 총 154개 미디어 파일, 80,120,615바이트. 스타일 24종은 미디어 파일 개수와 구분한다.

외부 자료 108개와 직접 제작 46개를 manifest의 origin으로 구분한다. 출처·저작자·라이선스·원본/가공본 SHA-256을 보관한다. 모든 인터넷 소재나 유료 편집기의 자료를 수집했다는 뜻이 아니다. 전체 출처는 [ASSET-SOURCES.md](ASSET-SOURCES.md), 실제 파일은 `Resources/Library`에 있다.

## 앱에서 사용

1. **사운드** 탭: 효과음/배경음 필터, 태그 검색, 미리듣기, 즐겨찾기, 플레이헤드에 삽입. 배경음은 기본 25% 볼륨과 짧은 앞뒤 페이드를 적용하며 현재 영상의 남은 길이에 맞춘다.
2. **소스** 탭: 오버레이/배경/텍스처 필터, 실제 PNG 썸네일, 출처 표시, 현재 위치에 추가. 추가된 PNG는 속성에서 길이·크기·위치를 편집한다.
3. **자막** 탭: 24개 스타일, 선택 또는 전체 자막의 스타일 변경, 사용자 스타일 저장, 자막 목록/문구 검색, UTF-8 SRT 가져오기/저장. 자막 문구 편집은 영상을 자르지 않는다.
4. **속성**: 글꼴·RGB색·외곽선·배경·여백·정렬·그림자·최대 줄 수, 위치·크기·회전·불투명도, 0.25–4배 일정 속도, 노출·대비·채도·크롭, 화면/소리 페이드.
5. **키프레임**: 플레이헤드를 클립 안으로 옮겨 위치/크기/회전/불투명도/볼륨을 입력하고 ‘현재 위치에 키프레임 저장’. 직선/유지/부드러운 보간 지원. 기본 속성 적용과 키프레임 저장은 별도 명령이다.
6. **타임라인**: Cmd 클릭으로 여러 클립 선택, 그룹 이동·삭제는 한 번에 실행취소. 경계/플레이헤드 자석 스냅, 원본 오디오를 읽어 생성한 파형. 속도 변경은 원본 구간을 유지하고 같은 트랙의 뒤 클립만 이동한다.
7. **프로젝트**: 9:16/16:9/1:1/4:5 독립 시퀀스 버전, 누락 미디어 재연결, 1.2초 디바운스 자동 복구본과 시작 시 복구 안내.

## 정확한 한계

- G1 전체 완료는 아니다. 삽입/덮어쓰기 편집, 연결 anchor, 프록시, 오디오 분리, 피크미터, 고급 전환 등은 남아 있다.
- 자동 음성 인식/자동 자막, 마스크·추적·크로마키, 속도 곡선, 브랜드키트, 출력 큐, 멀티캠, 전문 색 관리, 협업은 없다.
- 입력은 SDR 메타데이터가 확인되는 H.264, PNG, 디코딩 가능한 오디오다. HEVC/HDR/Log·색 정보 누락은 지원하지 않는다. 출력은 30fps SDR H.264/AAC MP4다.
- 화면 페이드는 클립의 알파 페이드다. 전용 두 클립 크로스디졸브 도구와 구분한다.
- 키프레임 또는 페이드가 있는 클립의 마우스 핸들 트림은 잘못된 애니메이션 변경을 피하기 위해 명시적으로 차단한다. 속성 숫자 편집은 유효한 범위만 허용하며, 페이드 진행 중 분할도 차단한다.
- 원본은 파일 참조다. 완전한 미디어 패키지 복사 기능은 없으므로 원본을 이동하면 재연결이 필요할 수 있다.
- 실시간 재생 드롭 수, 광범위한 카메라 코덱, macOS14 실기기/Intel, 공개 배포 공증은 검증하지 않았다.
