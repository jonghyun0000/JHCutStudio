# Native app screenshot provenance

These are unchanged JPEG captures of the actual **JH CUT Studio 0.7.0, build 8** local development app, taken on 2026-10-16 KST with the public **Vertical Story** sample open. The app was a locally built, ad-hoc-signed development build, not a signed/notarized public installer.

The captures show the Snapshot4-era UI with 389 localization entries, **before** the later 65-entry Auto Captions English follow-up. They are not post-change screenshots or verification of that follow-up. English coverage is partial: the Inspector visibly retains Korean controls. They are still images, not a usage recording, an ASR/translation result, or another-Mac installation test.
