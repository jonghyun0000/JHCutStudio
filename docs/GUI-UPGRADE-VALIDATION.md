# 0.2 네이티브 GUI 검증 — 2026-09-20

실제 macOS 앱을 CUA로 조작했습니다. 개인 영상 대신 기존 G0 합성 픽스처와 이번 라이브러리를 사용했습니다. 기본 문서는 보존하고 `Artifacts/Upgrade-GUI/GUI-upgrade.jhcut` 사본에서 편집했습니다.

## 확인한 흐름

1. 저장된 G0 문서를 0.2 앱에서 열고 기존 15초 시퀀스·한국어 제목·PNG·음원을 확인.
2. 사운드 탭에122개가 표시됨. ‘희망’ 검색 → ‘희망의 끝 · 잔잔한 피아노’1개. 미리듣기 버튼이 정지로 바뀌고 오류 없이 재생 상태로 진입.
3. 음원 삽입 후 원본183.04초가 영상의 남은15초에 맞춰 배치됨. 볼륨25%, 앞뒤 각1초 오디오 페이드. Emma_MA/CC0/원본 페이지 표시와 문서의 provenance 보존 확인.
4. 전체 자막에 강조 스타일 적용. 노란 글자와 검은 외곽선이 실제 미리보기/출력에 반영됨.
5. 별도 사본 저장 → Cmd+Q로 앱 종료 → 업데이트 빌드 실행 → 저장 문서 다시 열기. 음원과 스타일 보존.
6. `timing-boundaries.srt` 가져오기. 한글2행 자막의 시작12.017초, 길이2.034초가 속성에 표시됨. 글자 크기를64로 바꿔 Return으로 적용하고 저장한 뒤 JSON의 정확한 유리수 값12017/1000,1017/500을 확인. 글자 편집으로 타이밍이 바뀌지 않음.
7. 소스 탭32개 표시 → ‘오른쪽 포커스 화살표’ 삽입. 직접 제작/CC0 표시, 실제 투명 PNG와5초 길이 확인.
8. 최종 빌드 재실행 → 사본 재열기 → 전체 클립 팝오버에서 겹쳐 있던 기존 BGM440Hz 테스트 톤 선택/삭제. 수집한 피아노 음원을 남김. 재생 버튼의 일시정지 전환을 확인했으나 실시간 드롭 수나 지연은 측정하지 않음.
9. Cmd+S 저장 → Cmd+E → `GUI-upgrade-final.mp4` 출력. 앱에서 ‘출력 완료’ 확인. 기존 출력 덮어쓰기는 하지 않음.
10. 완료된 MP4를 CLI의 `--inspect`로 다시 디코딩하고1초/13초 프레임을 시각 확인.
