- **정확도 평가: 불가.** 세 영상 옆에 사람이 만든 대본(.srt/.txt)이 없다. 평가기는 “대본 없음 · 정확도를 계산하지 않았습니다”를 반환했고, CER/WER은 계산하지 않았다. 위 수치는 속도와 비음성 위 자막 수이며 인식 정확도가 아니다. 대본 기반 CER/WER은 합성 TTS 음성에서만 측정했다(2단계: 한국어 0.0%, 일본어 CER 15.3%/WER 16.7%, 영어 0.0% — 합성 음성이라 실사 정확도를 뜻하지 않음).

## 구현하지 않았거나 검증하지 못한 것

- **Developer ID 서명·공증·staple 실제 실행 안 함**(인증서·공증 프로필 없음). 자격 증명 없는 사전 점검과 절차만 검증했다. ad-hoc 서명 + hardened runtime 사본은 Team ID가 없어 dylib 로드가 거부됨을 확인했으며, 같은 Developer ID로 서명하면 해결되는지는 인증서가 있어야 확인된다(배포 스크립트가 제출 전 Team ID 일치와 실행을 검사).
- **다른 Mac 설치 미검증.** 같은 Mac에서 빈 홈 폴더로 실행(첫 실행 모사)만 했다.
- 화자 분리 모델 없음: 채널이 분리된 녹음에서만 화자를 구분한다. 한 대의 폰으로 녹음한 실사 영상은 “불확실”.
- 한 창 안에서 언어가 바뀌는 대사의 문장별 재인식은 하지 않았다(일본어가 한국어 창에서 한글로 음차되는 사례 확인).
- 번역 말투 변환은 문장 끝 규칙 기반이며 불규칙 활용·의문문은 번역기 문장을 유지한다. 번역 품질 점수는 측정하지 않았다.
- 출력 검사의 ‘화면 밖 자막’ 오류 경로는 유효한 프로젝트로 발생시키지 못했다(렌더러가 화면 안으로 유지).
- 음악/소음 사이의 4초 미만 짧은 말은 인식하지 않는다. 긴 영상 측정은 오디오만이며 60·120분은 같은 영상의 반복이다. small 모델·영상 디코딩 포함 측정은 하지 않았다.
- 체크포인트 식별자에 파이프라인 버전을 넣어, 이전 버전에서 만든 체크포인트는 재사용하지 않는다(다시 인식).
